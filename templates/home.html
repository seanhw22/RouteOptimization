{% translate 'Methodology' %}

Greedy

{% translate 'A fast constructive heuristic that builds routes by inserting the nearest feasible customer at each step. Serves as a quick baseline solution with minimal computation time.' %}

HGA — {% translate 'Hybrid Genetic Algorithm' %}

{% translate 'Combines genetic algorithm operators (selection, crossover, mutation) with local search to balance solution quality and runtime. Effective for medium to large instances.' %}

MILP — {% translate 'Mixed-Integer Linear Programming' %}

{% translate 'A mathematical optimization model solved by Gurobi that guarantees optimal solutions. Best suited for small instances (up to 25 nodes) due to exponential complexity growth.' %}
